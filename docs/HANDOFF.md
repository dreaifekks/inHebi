## 用户做过的决定

这些是用户在使用后明确提出或拍板的，改动前先确认是否仍然成立。

- 收藏星标实心只表示“在默认收藏夹里”，短按切换默认收藏；只在其他收藏夹时为空心，按钮文字显示所在收藏夹数量，长按仍打开多收藏夹选择列表。
- 应用改名 inHebi，bundle ID 为 `com.dreaife.inhebi`，iCloud 容器为 `iCloud.com.dreaife.inhebi`；内部工程名称统一为 inHebi，SwiftData 模型名和属性保持不变。
- 列表：横版 4 列、竖版 5 列。没选 3 列是因为 Hanime1 缩略图原图只有 640 像素宽，放大会糊。
- 筛选条：聚焦即切换，焦点停留 0.4 秒后加载，不需要按确认。这推翻了 UX 规格里“按下才切换”的设计。
- 筛选条位置：左边是可横向滚动的芯片，最右边固定排序（或分级）和搜索。
- iwara 默认趋势，趋势排第一。芯片选择不跨启动记忆，每次打开都从第一个开始；右侧的排序、分级设置跨启动记忆。
- 漫画分类全部平铺在条上，子类写成“大类·子类”。
- 返回键：在网格里先回顶部并聚焦筛选条，再按才到顶部系统标签栏。
- 芯片不要勾号，用颜色表示选中，每个分类前有 SF Symbol 图标。
- 卡片上按播放/暂停键直接播放视频或直接进阅读器。
- 阅读器默认左键下一页（日漫从右往左），设置里可以改方向。
- 双页阅读两张图片按同一高度完整适配、内侧无缝拼接，整体居中，保留跨页图接缝。
- 双页从指定页开始配对：跳到或续读第 N 页显示 N/N+1，默认 N 在右、从左往右时 N 在左；每次前进/后退两页，不按奇偶对齐。
- 阅读页码在右下角，小而不抢眼；控制面板打开时预览页码也靠右、位于按钮行上方。
- 控制面板最底按钮行再按下，关闭面板并继续阅读。
- 阅读器同键呼出同键收起：上键呼出到当前页缩略图、顶部再按上收起；下键呼出到“继续阅读”、底部再按下收起。Select/播放暂停呼出也落到当前页；双页落在当前起始页 N，目标滚到可见后才交焦点。
- 防止一次滑动连续呼出/收起：方向呼出后的初始 1 秒抑制同方向边缘关闭，后续连发延长到至少 350ms 静默，且不缩短初始窗口；方向收起后也要求同方向 350ms 静默才能重开，连发延长；快速再次点按也受限制，触控面手感待用户确认。
- 视频按同原则核对后保留 AVKit：上为进度栏/工具、下为 Info、Select 暂停/继续。移除外层 SwiftUI 的 Menu 直接退出，让系统先收原生层再退出。AVKit 公共 API 不能强制同方向收起原生面板，不用私有接口或替代播放器；轻触/指腹滑动仍需实体遥控器确认。
- 卡片保留系统聚焦放大幅度，封面和标题留足空间；横版四列、竖版五列。封面占满整列、与标题左缘对齐，横版 16:9、Hanime1 竖版 2:3、漫画 3:4；不按视口高度缩小或压缩封面。协调者撤回“首屏完整两行”约束，允许竖版第二行部分露出。
- 应用图标用概念 1“架上的书和播放屏”。另外两个概念的预览和全部源文件在 `artifacts/icon/`（被 gitignore，只在这台 Mac 上）。
